# Engineering roadmap

## P0 — Reproducibility and hygiene
- Inventory source archives and select canonical versions.
- Exclude runtime state and secret-bearing configuration.
- Establish independent smoke tests, CI and error reports.
- Document tested environment and open bugs (especially MOSS Windows/Ollama).

## P1 — MOSS/KYVRAEL
- Validate imports, CLI, autonomy states, persistence and SQLite close paths.
- Reproduce user-observed failures rather than claiming all bugs fixed.
- Integrate local models using explicit timeout, permission and dry-run controls.

## P1 — RV32I-TRACE processor
- Verify RTL simulation and reference tests; run ISA compliance where applicable.
- Measure architecture, timing and area in real synthesis toolchain.
- Review originality and licensing **before** commercial disclosure.

## P2 — Other pilots
- ARKHÉ: preregistration, blind evaluation, external datasets.
- KIM: strictly paper execution, risk caps and reproducible statistics.
- TR-003: motor torque/temperature measurements and CAD/structural design.
- PROMETHEUS: real-camera and real-part evaluation after synthetic datasets.
- GENESIS X: phased Android/reference-board feasibility and documented satellite connectivity pathway.
- Website: publish only demonstrated statuses and verified contact information.

All milestones require evidence, not just project names.
