# C.E.R.B.E.R.U.S. — Core Commander

**Ferramenta experimental de assistência a engenharia de software, para ambiente Windows.**

A versão de investigação contém análise e auditoria estática, relatórios, histórico, regras de segurança e testes de regressão. A cópia de fonte canónica está guardada num repositório privado; builds, relatórios locais e contactos não são publicados.

**Evidência:** 104 testes locais Windows aprovados em 9/11/2026 (1 ignorado). Testes automatizados adicionais em GitHub Actions Windows aprovados. Estes resultados não representam aprovação por clientes, certificação ou software de produção.

**Importante:** o Core Commander é diferente do novo Control Plane. A integração entre os dois ainda não está concluída. A versão pública não distribui um instalador nem fornece controlo irrestrito de computador.

Para um piloto supervisionado, utilizar os contactos e o mecanismo de issues públicos do portefólio sem partilhar código confidencial, senhas ou dados pessoais.
