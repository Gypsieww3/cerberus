# KIM / Quant Lab & trading research

Located ZIP: `KIM_INDEPENDENTE_v0_6_1.zip`.

The archived KIM README describes a **paper/synthetic** trading research prototype with a risk governor, shadow portfolios, append-only audit ledger and kill switch. Live trading is not implemented in that version.

Any external broker API credentials and account data must remain out of this public repository. Backtests and demos do not guarantee profits.
